# ContextIQ: Agentic Playwright Orchestrator

An AI-powered engineering intelligence platform built on **Atlassian Forge** that converts raw CI/CD test execution realities into predictive project delivery insights. By connecting cross-browser **Playwright E2E automation validations** with **Jira, Bitbucket, Confluence, and the Teamwork Graph**, ContextIQ proactively intercepts structural software regressions and delivery bottlenecks before they result in milestone failures.

## 🚀 The 4-Part Core Architecture
ContextIQ answers four critical software delivery questions directly inside the Jira Issue Panel:
1. **What could go wrong?** – Predictive Quality Risk Alert (PR & Test Flakiness Analytics).
2. **Why did it go wrong?** – Contextual Investigation (Playwright Error Trace + DOM Diff Parsing via Atlassian Rovo).
3. **What happens if we change something?** – Cross-Browser Pipeline Execution Simulation (Playwright Runner via GitHub Actions).
4. **What should we do now?** – Autonomous Rovo Agent Actions with explicit human-in-the-loop approval gates.

## 🛠️ Tech Stack
* **Frontend:** Atlassian UI Kit (React-based architecture)
* **Backend:** Forge Serverless Runtime (Node.js 22.x)
* **Database & Knowledge:** Forge SQL & Atlassian Teamwork Graph
* **AI Orchestration:** Atlassian Rovo / Model Context Protocol (MCP)
* **Automation Infrastructure:** GitHub Actions Pipelines + Playwright (TypeScript)
